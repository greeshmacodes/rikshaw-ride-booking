# Rikshaw Ride Booking Application

A ride-booking application developed using Flutter and Dart for the mobile application and Python, Django, and MySQL for backend development. It allows users to book rickshaw rides and manage ride-related information.

## Technologies Used

* Flutter
* Dart
* Python
* Django
* MySQL
* HTML, CSS, JavaScript

Database:
MySQL

Main Features:
User registration and login
Rikshaw ride booking
Ride management
User and driver-related functionality
Management of ride-related information
Mobile application interface
Web-based backend and management system

Project Components:
Flutter Mobile Application

The Flutter application provides the mobile interface through which users can interact with the ride booking system and manage their ride-related activities.

Django Web Application:

The Django application provides the backend functionality, web interface, and database connectivity required for managing the ride booking system.

Project Purpose:

The purpose of this project is to provide a convenient ride booking platform that combines a Flutter mobile application with a Django web-based backend for managing rikshaw rides.
