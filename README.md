Rikshaw Ride Booking

Rikshaw Ride Booking is a full-stack ride booking application developed with a Flutter mobile application and a Django-based web backend. The system allows users to book rikshaw rides and provides functionality for managing ride-related information.

Project Components
Flutter Mobile Application

The Flutter application provides the mobile interface through which users can interact with the ride booking system and manage their ride-related activities.

Django Web Application

The Django application provides the backend functionality, web interface, and database connectivity required for managing the ride booking system.

Project Purpose

The purpose of this project is to provide a convenient ride booking platform that combines a Flutter mobile application with a Django web-based backend for managing rikshaw rides.
